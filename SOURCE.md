# Source

This repository is an ASC Team study fork. It is not an official ASC Committee repository, and it is not a university endorsement.

- Contest: ASC26 (2026)
- Upstream: https://github.com/ASC-Competition/AMSS-NCKU
- This fork: https://github.com/hkust-asc/asc2026-amss-ncku

## What is in this fork

Official committee copy of the AMSS-NCKU numerical relativity code and example inputs, published on the ASC-Competition account. The official finals notification lists the software download as https://github.com/ASC-Competition. The finals workload itself was to be announced on site and is not in this repository.
